# 第七章｜场面调度（Mise-en-Scène·北电导演系核心）

## 7.1 演员调度类型（11种）

| 调度类型 | 定义 | 典型适用 |
| --- | --- | --- |
| **横向调度** | 演员从画面左→右/右→左移动 | 穿越空间 |
| **纵向调度** | 演员从前景→背景/背景→前景 | 角色走近/走远 |
| **斜向调度** | 演员沿对角线移动 | 斜切逼近 |
| **环形调度** | 演员绕圈/弧线运动 | 仪式感/对峙 |
| **对角线调度** | 两人分占画面对角 | 对峙（左上vs右下） |
| **三角形调度** | 三人形成三角站位 | 三方博弈 |
| **交叉调度** | 两人路径交叉 | 擦身而过 |
| **对称调度** | 左右镜像对称 | 仪式感/双人对立 |
| **不对称调度** | 刻意打破平衡 | 强者居中占大→弱者缩角落=权力不均 |
| **静态调度** | 演员不动，摄影机动 | 静立+环绕=气场展示 |
| **动态调度** | 演员与摄影机同时运动 | 追逐/打斗 |

## 7.2 演员×摄影机综合调度（5种模式）

| 综合模式 | 定义 | 效果 |
| --- | --- | --- |
| **演员动+摄影机不动** | 固定机位记录运动 | 客观/冷静/纪录 |
| **演员不动+摄影机动** | 推/拉/环绕静止角色 | 内心状态/气场展示 |
| **同向运动** | 演员和镜头同方向 | 跟随/共情/陪伴 |
| **反向运动** | 演员向前+镜头向后 | 对峙/压迫/逼近 |
| **交叉运动** | 演员横向+镜头纵向 | 复杂空间感/时间感 |

## 7.3 空间调度（含人际距离心理学）

| 空间类型 | 定义 | 心理效果 |
| --- | --- | --- |
| **纵深调度** | 利用前中后景的深度关系 | 层次/复杂/秘密 |
| **平面调度** | 主要在同一平面展开 | 直接/对峙/平等 |
| **封闭空间** | 墙壁/门窗围合 | 困境/压迫/窒息 |
| **开放空间** | 天空/远山/庭院 | 自由/希望/孤独 |

**人际距离心理学**（阿尔伯特·梅拉比安）：

| 距离 | 范围 | 心理含义 | 适用关系 |
| --- | --- | --- | --- |
| **亲密距离** | 0-45cm | 亲密/威胁 | 爱人、亲人、敌对近身 |
| **个人距离** | 45-120cm | 私密/信任 | 朋友、熟人 |
| **社交距离** | 120-360cm | 礼节/距离感 | 同事、陌生人 |
| **公共距离** | 360cm+ | 权力/演讲/审判 | 公众人物、权力者 |

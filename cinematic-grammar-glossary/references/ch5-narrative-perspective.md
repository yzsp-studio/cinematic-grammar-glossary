# 第五章｜叙事视角系统（Narrative Perspective System）

## 5.1 五种基础视角

| 叙事视角 | 定义 | 观众能感知什么 | 镜头语言实现 |
| --- | --- | --- | --- |
| **第一人称** 1st Person | 观众=角色本人的眼睛 | 只看到角色所看到的 | POV镜头 + 主观渐显 + 呼吸感手持晃动 |
| **第二人称** 2nd Person | 角色直视镜头=直视观众，打破第四面墙 | "你"被卷入叙事 | 角色正面直视镜头，瞳孔锁定镜头光轴 |
| **第三人称零聚焦** Omniscient | 叙事者无所不知 | 全知视角，多线并行 | 上帝俯视全景 + 自由切换各角色特写 + 蒙太奇 |
| **第三人称内聚焦** Internal Focalization | 跟随一个角色的主观感知 | 知道该角色心理+所见 | 过肩镜头 + 跟拍 + 景深虚化（焦点=角色关注的事物） |
| **第三人称外聚焦** External Focalization | 冷眼旁观，只见行为不知内心 | 仅看到动作和对话 | 远景固定机位 + 长焦压缩 + 不给特写 |

## 5.2 第一人称细分（5种）

| 视角 | 定义 | 典型适用 |
| --- | --- | --- |
| **主人公视角** | "我"是故事主角 | 主角独白段落 |
| **见证人视角** | "我"是旁观的次要角色 | 配角视角看主角冲突 |
| **回顾性视角** | 事后回忆式叙述 | 回忆童年（距离感+评价） |
| **体验性视角** | 即时体验式叙述（当下） | 角色苏醒的即时感受 |
| **多重叙事视角** | 多个"我"交替叙述 | 双主角交替内心独白 |

## 5.3 第二人称细分（5种）

| 视角 | 定义 | 典型适用 |
| --- | --- | --- |
| **直接视角** | 直接对"你"说话 | 角色直视镜头 |
| **间接视角** | 暗示"你"的存在但不直接称呼 | 独白似乎在对某人说话 |
| **命令式视角** | 指令性的"你去做X" | 角色指导另一角色 |
| **邀请式视角** | 邀请"你"参与/思考 | 集尾悬念氛围暗示 |
| **反思式视角** | "你"是角色自己——自我审视 | 角色内心自问 |

## 5.4 第三人称细分（8种）

| 视角 | 定义 | 典型适用 |
| --- | --- | --- |
| **全知视角** Omniscient | 知道所有角色的一切 | 默认叙事模式（80%场景） |
| **选择性全知** Selective Omniscient | 全知但刻意隐瞒部分信息 | 隐藏某角色真实身份 |
| **固定内聚焦** Fixed Internal | 始终跟随一个角色的内心 | 角色独处段落 |
| **可变内聚焦** Variable Internal | 在不同角色间切换内聚焦 | A段=角色A视角→B段=角色B视角 |
| **多重内聚焦** Multiple Internal | 同一事件从多角色视角呈现 | 同一事件三方各自感受 |
| **外聚焦** External | 只看行为不知内心 | 制造悬念 |
| **零聚焦** Zero | =全知 | 同上 |
| **纯客观视角** | 摄影机=冷漠旁观者 | 远景固定机位记录事件 |

## 5.5 特殊视角（10种）

| 视角 | 定义 | 典型适用 |
| --- | --- | --- |
| **自由间接引语** Free Indirect | 第三人称叙述混入角色语气 | "她看着他——这个人居然还敢嚣张？" |
| **内心独白** Interior Monologue | 角色思维直接呈现 | 画外音内心独白 |
| **意识流** Stream of Consciousness | 无逻辑的意识流动 | 非理性画面段落 |
| **梦境视角** Dream POV | 梦中的非现实逻辑 | 噩梦段落 |
| **回忆视角** Memory POV | 以记忆方式重现过去 | 去饱和+模糊边缘标记 |
| **幻觉视角** Hallucination | 角色看到不存在的事物 | 恐惧中"看到"已故之人 |
| **复调视角** Polyphonic | 多个平等声音共存 | 多角色各有各的道理 |
| **流动视角** Flowing | 视角在多角色间自由流动 | 群像场景自由切换 |
| **上帝视角** God's Eye | 超越所有角色的命运俯瞰 | 全剧开篇/结尾宏观叙述 |
| **物体视角** Object POV | 从物件的"视角"观看 | 从道具角度看角色拿起它 |

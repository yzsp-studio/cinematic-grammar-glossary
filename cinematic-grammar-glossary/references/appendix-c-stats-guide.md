## C.2 使用指南

### 对 Skill 开发者

1. **作为知识库引用**：将本文档放入 Skill 的 `knowledge/` 目录，Skill 运行时可按章节检索术语
2. **提示词构建**：撰写视频/图片提示词时，从对应章节提取精确术语替代模糊描述
3. **角色塑造**：用 `video-prompt-craft`（表情/眼神/呼吸）+ `character-body-language`（肢体/步态）+ 第12章（演技体系）联动构建角色表演指令
4. **质量检查**：每个输出使用附录B自查清单逐项核对，使用附录A修正清单排查AI通病

### 对导演/策划者

1. **前期策划**：用第13章风格模板锁定项目视觉调性
2. **分镜设计**：从第4章选取镜头语言+第7章设计调度+第8章规划节奏
3. **表演指导**：用第12.5节标准格式撰写表演指令（方法派路径）
4. **后期审核**：对照附录B清单逐项验收

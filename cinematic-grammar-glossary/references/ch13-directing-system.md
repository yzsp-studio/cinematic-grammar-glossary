# 第十三章｜导演技能体系（北电/中戏/上戏导演系核心）

> 本章为AI短剧制作中"导演决策"的理论框架——指导分镜设计/拍摄/剪辑的系统方法。

## 13.1 剧本分析五维度

| 维度 | 分析内容 | 通用示例 |
| --- | --- | --- |
| **主题分析** | 全剧核心表达（一句话主题） | "复仇不是终点，和解才是成长" |
| **结构分析** | 时间线/叙事线/情感线 | 多线交织(主线+副线)+特殊结构线(倒叙/多视角) |
| **人物分析** | 性格弧+内在需求+外在目标 | 主角：外在=完成任务 / 内在=获得认同 |
| **情节分析** | 节拍/转折/高潮/低谷 | 每集遵循5节拍(钩子→建置→对抗→高潮→钩子) |
| **语言分析** | 台词风格/潜台词/语言节奏 | 不同角色使用不同语言风格(简洁/文雅/粗犷/含蓄) |

## 13.2 演员指导方法（5法）

| 方法 | 操作 | AI提示词适用性 |
| --- | --- | --- |
| **结果导向** | 直接告诉想要的效果 | "这里需要更害怕" → ❌ 不推荐(太抽象) |
| **动作导向** | 给具体可执行的动作 | "右手搓捻衣角加速到3Hz" → ★ 强烈推荐 |
| **情境导向** | 创造角色所处的情境 | "想象被关在黑暗房间3天" → ✅ 构建动机 |
| **潜台词导向** | 告诉角色"真正在想什么" | "台词说'没事'，内心在喊'救命'" → ✅ 生成矛盾表演 |
| **节奏导向** | 控制表演的速度和停顿 | "反应延迟0.5s再给" → ★ 反AI呆板的关键 |

> ⚠️ **AI视频专项修正**：AI模型对「结果导向」指令（如"look scared"）的响应是统计平均表演，所有角色都呈现相同的"标准恐惧脸"。**动作导向**是AI表演指导的最佳路径——用可执行的物理动作替代情绪描述。**节奏导向**是对抗AI呆板的核心武器——AI默认所有反应都即时发生，必须手动注入延迟/停顿。

## 13.3 导演风格构建框架（通用模板）

> 以下为通用风格锁定框架，使用时根据具体项目填入参数值。

```
【导演风格锁定模板】

视觉调性：[写实主义 / 表现主义 / 超现实 / 极简 / 浓郁]
  色彩基调：[低饱和+高对比 / 高饱和+低对比 / 单色调 / 互补色系]
  光影原则：[自然光优先 / 戏剧光优先] + 各情绪对应光型

表演风格：[方法派微表情 / 话剧放大 / 纪实自然 / 程式化]
  情绪密度：文戏>[X]s一个微表情变化 / 武戏>[Y]s一个动作

剪辑节奏：[呼吸式节奏 / MTV快剪 / 纪录片长镜 / 混合式]
  文戏=每镜头[A]s → 情绪高潮变速 → 转折点断裂
  武戏=快切+Speed Ramp+长镜头交替

音频原则：[环境音>BGM>台词 / BGM驱动 / 对白驱动]
  对白时BGM [X]dB → 高潮BGM上升 → 关键台词前BGM骤停[Y]s
```

> 💡 **使用说明**：每个项目开始前，导演（或AI Skill策划者）应基于此模板填写具体参数，锁定为项目级「风格锚点」。所有分镜、提示词、剪辑、配乐均需对照风格锚点执行，确保全片风格统一。

# 第十二章｜演技技能体系（中戏/北电/上戏表演系四年制核心）

> 本章为AI视频生成中"表演指导"的理论基座——指导提示词中的动作/情绪/角色塑造。

## 12.1 基础技能（5项）

| 技能 | 定义 | AI生成中的体现 |
| --- | --- | --- |
| **台词设计** | 吐字归音+气息+情感+节奏 | 对白的语气标注(括号表演指导) |
| **形体表现** | 柔韧+协调+控制+表现力 | 肢体动作的精确描述 |
| **观察生活** | 提炼真实人物特征 | 角色细节来源(如"指甲掐掌心""搓捻衣角") |
| **想象力** | 无实物练习+情境构建 | 非现实空间的表演(梦境/幻象/意识流) |
| **注意力** | 专注力+排除干扰+沉浸角色 | 角色在多人场景中的反应设计 |

## 12.2 斯坦尼斯拉夫斯基体系（6大技术方法）

| 技术方法 | 定义 | AI提示词应用 |
| --- | --- | --- |
| **贯穿动作** (Through-action) | 角色在全剧中追求的根本目标驱动每一个具体行动 | 每个镜头的角色动机必须能追溯到全局目标 |
| **最高任务** (Super-objective) | 角色存在的终极意义/核心需求 | 构建角色时先定义最高任务→推演每场戏的具体行动 |
| **情绪记忆** (Emotional Memory) | 调取演员个人经历的情绪用于角色 | 为AI角色设定"创伤记忆"→触发条件性反应 |
| **形体动作方法** (Method of Physical Actions) | 从具体外部动作出发激活内在情绪 | ★ AI最适用——先写动作→情绪自然产生 |
| **交流与适应** (Communication & Adaptation) | 与对手演员的真实互动而非预设反应 | 对手戏中角色B的反应必须基于角色A的具体行动 |
| **公众孤独** (Public Solitude) | 在公众环境中创造私密的内心空间 | 多人场景中的角色独处状态：周围喧嚣但角色沉浸自我世界 |

> 💡 **公众孤独**（Public Solitude）是斯坦尼体系中常被忽视的概念：角色在公共场合中表现出仿佛周围无人的私密状态。AI生成中可通过「角色视线不与任何人交汇+微动作自我安抚+环境音弱化」实现。

## 12.3 方法派核心技术（5术 + 代表演员）

| 技术 | 定义 | 代表演员 | AI提示词写法 |
| --- | --- | --- | --- |
| **情绪记忆** Emotional Memory | 调取个人经历的情绪用于角色 | 罗伯特·德尼罗 | 设定角色的创伤记忆→描述触发时的身体连锁反应 |
| **感官记忆** Sense Memory | 五感的记忆与再现 | 阿尔·帕西诺 | 描述触发感官："热辣感→条件反射闭眼""冰冷触感→缩手" |
| **替代法** Substitution | 用已知情感替代角色情感 | 梅丽尔·斯特里普 | "角色的恐惧"替代为具象场景："初入漆黑密林的无助" |
| **动物练习** Animal Exercise | 以动物行为特征构建角色外在 | 杰克·尼科尔森 | "猫科动物的慵懒→突然捕猎""鹰隼的扫视锁定" |
| **化身法** Transformation | 完全变成角色(方法准备) | 丹尼尔·戴-刘易斯 | 角色的肢体签名贯穿全片不脱落 |

> **方法准备**（Method Preparation）：部分方法派演员在拍摄期间完全以角色身份生活（如丹尼尔·戴-刘易斯）。AI生成中的对应原则：同一角色在不同镜头间的行为模式必须保持绝对一致——不能"这个镜头温柔下个镜头突然暴烈"，除非有明确的情节触发。

## 12.4 角色塑造方法论（4派）

| 方法 | 内→外 | 外→内 | 适用场景 |
| --- | --- | --- | --- |
| **体验派** | ★★★ | ★ | 从角色内心恐惧出发→自然产生退缩行为 |
| **方法派** | ★★★ | ★★ | 用情绪记忆激发真实泪水(非开关式假哭) |
| **表现派** | ★ | ★★★ | 程式化反派(外部技巧驱动的精准邪恶) |
| **综合法** | ★★ | ★★ | "伪装"型角色=外部控制+内心翻涌(表里不一) |

## 12.5 AI生成中的"表演指导"标准格式

```
【分镜表/提示词中的表演指导写法】

❌ 错误："角色很害怕"（抽象情绪标签）
❌ 错误："角色表现出恐惧"（还是标签）

✅ 正确（方法派路径）：
  1. 内在动机：角色被踹醒→童年创伤记忆被激活
  2. 身体反应：心跳加速→肾上腺素→肌肉僵硬
  3. 外在表现：
     面部 = 额肌AU1+AU2全收缩+提上睑肌AU5瞬间激活→瞳孔骤扩
     身体 = 肩膀内收+重心后移+双手攥衣角
     呼吸 = 频率30+/分→锁骨可见起伏
     眼神 = 瞳孔放大+快速闪避+不敢停留
     微动作 = 右手食指拇指搓捻衣角(速度越快=越紧张)
  4. 声音：嘴唇张开但没有声音(被训练出的无声恐惧)
```

> ⚠️ **AI视频专项修正**：AI模型对"sad""angry"等情绪标签的理解是统计平均值，会产生模板化表演。必须用**肌肉级描述**（AU编码+具体动作）替代情绪标签。方法派路径（动机→身体→外在→声音）是最适合AI的表演指导结构。
